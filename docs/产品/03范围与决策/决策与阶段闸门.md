# 决策与阶段闸门

更新：2026-10-14；本轮文档设计，无应用实现。区分用户决定、实施者默认和未决事项。

## 已明确

- 保留原鸿蒙项目；新增iOS方向，React Native + TypeScript；共用Python FastAPI后端。
- 独立GitHub、新环境与数据库，禁止操作旧Gitee；不迁入旧历史。
- 首版用户名/邮箱密码登录；短信后续。
- AI只能使用免费接口，不默认开通付费；未指定可用模型/提供方。
- 地图已有高德使用背景，iOS又讨论过Google Maps；尚无最终iOS供应商决定。
- 不扩展订单支付预订；先测试数据闭环，后授权真实样本，再扩大数据。

## 本轮常规设计默认（可评审调整）

模块化单体、PostgreSQL+Alembic；数据库任务worker；两端目录分离，业务契约共享。iOS先推进工程验证，鸿蒙继续保留并独立安排适配；这不是将鸿蒙移出产品范围。若只先验收iOS，不自动视作双端闭环通过。

保留现有单城市、CNY、Asia/Shanghai基础。首次UI采用首页/行程/我的三入口；默认内置头像、仅地点收藏，不做自定义地点及离线编辑。iOS拟采用可管理原生工程的React Native工作流，具体版本在工具链验证后锁定；不在本轮安装。
