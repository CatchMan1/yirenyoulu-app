# 版本范围与发布条件

## 版本约束

鸿蒙与iOS共用业务接口，分别实现与验收。首版采用用户名/邮箱密码登录、地点收藏、单城市行程、地图导航、AI伴游与真实行为推荐；不包含交易、订阅和社交功能。

单城市、CNY、Asia/Shanghai为首版数据基线。面向其他时区和币种发布前，需扩展契约与测试。界面使用首页、行程、我的三个主入口；内置头像，暂不支持自定义地点和离线编辑。

AI使用免费且许可适用的服务；额度不足时返回不可用，不自动切换付费。地图、模型、邮件和应用发布账号分别配置，费用和商业条款经项目负责人确认。

## 待决事项

| 事项 | 状态 | 影响 |
|---|---|---|
| 首发地区及城市 | 待定 | 地图覆盖、时区币种及商店准备 |
| iOS地图供应商 | 高德/Google Maps候选 | 真实地图和导航验收 |
| 免费AI提供方、模型及商业许可 | 待定 | 真实规划及伴游验收 |
| 邮箱验证及找回渠道 | 待定 | 账户恢复 |
| Apple/Huawei开发者主体与应用标识 | 待定 | 签名和发布 |
| 数据来源、数量、许可与费用 | 测试闭环后确定 | 正式数据导入 |

## 交付条件

1. 产品、接口和数据结构一致，DTO/OpenAPI与文档相符。
2. 数据库迁移、约束、隔离及备份恢复通过验证。
3. 测试数据覆盖关键API、两端页面、权限、事务和任务并发；模拟服务与真实服务验证分别记录。
4. 关键闭环验收后，确认数据授权与费用，先导入少量真实样本验证，再扩大范围。
5. 替换测试数据后完成真实数据回归，验证更新、失效、缺失事实与快照稳定。
6. 部署、恢复、签名、隐私和商店材料满足发布要求。两端独立验收，单端结果不能替代另一端。
