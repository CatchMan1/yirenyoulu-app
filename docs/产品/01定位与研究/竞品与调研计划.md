# 竞品与调研计划

依据用户提供的旧调研：指北旅行、TripIt、Wanderlog等截图与文字。采样日期、版本、授权及完整来源未齐备；本轮未重新联网验证这些产品，不把旧功能或价格描述当成当前事实。原截图仅保存在本地历史资料，不直接作为新版可商用素材。

## 从旧材料提炼的设计问题

| 旧观察所提示的问题 | 新版采用的设计 | 如何验证 |
|---|---|---|
| AI入口多且行为不一致 | 规划入口进入同一表单，伴游入口进入同一会话功能 | 两端入口行为一致 |
| 地点与地图割裂 | 每日列表与地图选择同一地点ID | 切换日期后标记与列表对应 |
| 酒店等详情错误复用景点字段 | 按kind显示计价单位与类型信息 | 无酒店“入园时间”文案 |
| 推荐内容覆盖不足 | 空结果、缺失事实和候选不足明确提示 | 不虚构地点补齐行程 |
| 管理功能过重 | 首版聚焦个人行程与地点收藏 | 无订单、社交、邮箱预订导入入口 |

以上是本项目设计选择，不构成对竞品当前质量的评价。

## 后续调研记录模板

每条观察记录产品名、平台、版本、采样时间、功能路径、事实截图授权、观察、解释和待验证假设。把看到的事实与主观判断分列；不复制竞品素材进正式应用。

用户访谈围绕最近一次独自旅行：准备耗时、地点筛选、预算理解、临时编辑和AI失败容忍。经同意再记录匿名反馈，不收集精确轨迹、身份证或无关敏感信息。测试数据闭环前不开展正式地点批量采集。
