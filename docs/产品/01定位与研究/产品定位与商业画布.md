# 产品定位与商业画布

产品定位与商业模式为待验证假设，以真实用户研究和运营数据评估。

一人有路帮助独自旅行者把“想去哪里”变成能查看、能修改、有事实来源的每日安排，并在旅行中提供有上下文的 AI 伴游。第一版用小规模可验证闭环检验价值，不以平台交易规模为目标。

| 画布部分 | 当前设计 |
|---|---|
| 用户 | 独自安排旅行、希望减少查找与排程成本的人；学生、年轻旅行者和 Citywalk 群体为访谈假设，不据此推断性别、健康或收入 |
| 价值 | 本次偏好优先、真实地点、每日安排可编辑、缺失信息可见、AI会话可延续 |
| 渠道 | 双端测试邀请及后续应用商店；不在本阶段投放或承诺推广效果 |
| 关系 | 明确失败原因、可重试、可删除账户和私有内容、用户主动反馈 |
| 收入 | 首版不做支付、订阅和佣金；商业模式以后单独评估，不售卖用户个人数据 |
| 资源 | 许可清楚的地点数据、共享后端、鸿蒙与iOS客户端、受控AI能力 |
| 活动 | 先闭环测试，再授权样本、回归与发布准备；持续修复错误与核验数据 |
| 伙伴 | 地图、模型、邮件、数据来源候选，未表示已有合作 |
| 成本 | 服务器、数据库、开发者账号、地图/模型/数据许可等需逐项确认；AI仅接受免费可用方案，额度不足停止请求 |

## 衡量方式

先记录测试通过率、生成任务成功/超时/校验失败数、行程编辑保存正确率及故障恢复结果。真实运营后再记录浏览→收藏、生成→查看/编辑的转化，按真实用户与有效行为统计。不得把测试事件计入运营或推荐效果指标。

首版不以交易或付费转化作为验收指标。满意度与留存目标需有真实样本后确定；不作安全、疗愈、女性夜行保障等无依据承诺。
