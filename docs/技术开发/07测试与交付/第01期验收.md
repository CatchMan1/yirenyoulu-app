## 鸿蒙源码交付边界

保留原工程的可复用公共组件、主题和资源，页面与请求层迁至新接口，包含六个入口页面。补充会话失效处理、分页、失效收藏取消、行程和任务恢复、AI 历史及错误重试。代码中使用无效占位 API 地址，开发者需配置真实开发服务地址。

本期未提供已签名安装包，也没有 ArkTS 编译、模拟器、真机、无障碍、权限、生命周期或前后端联调证据。令牌只在进程内保存，重启需要重新登录；平台受保护持久存储尚未实现。城市/标签选择和行程地点选择目前为首批候选，复杂条件筛选与大目录选择体验需在客户端验证阶段完善。上述限制不能标记为正式客户端需求完成。

源码修复中，取消收藏已不依赖有效地点详情；收藏、行程、任务和会话保留分页元数据与加载更多入口。此处描述为源码行为，平台效果仍待验证。
