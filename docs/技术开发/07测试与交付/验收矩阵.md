# 验收矩阵与证据要求

验收覆盖后端、鸿蒙和iOS。每条用例需记录实际结果及可复现证据。

| 用例 | 后端关键验证 | 鸿蒙/iOS分别验证 | 通过证据 |
|---|---|---|---|
| P01注册登录/账户 | 唯一性、密码哈希、轮换重放、撤销、限流、注销与worker竞争 | 注册201、刷新单飞、重新登录、改密/注销缓存清除 | API测试+双端录屏/操作记录 |
| P02公共目录 | 同过滤分页、输入约束、unknown与inactive过滤 | 搜索竞态、空/失败重试、图片/事实缺失 | 契约测试+页面证据 |
| P03收藏 | 幂等、跨用户404、失效仍能取消 | 防连点、失败回滚、账户切换 | 两用户隔离测试 |
| P04/P05行程 | 事务失败全回滚、version冲突、子资源归属、同城/日期/重复/预算校验、快照 | 保存失败无成功提示、409保留输入、按日地图同步 | PostgreSQL集成+双端联调 |
| P06Agent | 非法工具/注入/伪造ID、取消竞争、过期worker、deadline、幂等、保存失败 | 202/任务恢复/超时/取消/重试 | 多worker数据库并发测试+故障注入 |
| P07地图 | 坐标对/范围/CRS/导航域名/第三方失败 | 权限拒绝、缺坐标、SDK失败、未安装地图应用 | mock测试和独立真实真机证据 |
| P08伴游 | 其他用户session/trip拒绝、20条上下文、有界输入、同键异内容、失败复用槽位 | 多轮上下文、失败重试、回前台恢复、删除 | 模拟+免费模型真实验证分列 |
| P09推荐 | 事件去重/原子写、test排除、阈值兜底、硬条件过滤、权重与相似度 | reason展示、刷新、匿名兜底 | 可手算合成样本仅证明链路 |
| 环境与恢复 | prod拒绝mock、迁移往返、drift、恢复/删除重放 | 错环境标识、无秘密打包 | 独立库与构建审查 |

统一证据格式：日期、提交、平台/系统/SDK、环境、fixture版本、服务模式、步骤、期望、实际、证据路径、失败原因。状态只能为通过/失败/未执行/依赖外部；跳过不是通过。

四类证据分开：静态检查、后端自动测试、双端构建/模拟器与真机联调、真实外部服务。真实地图/模型缺凭据时可通过模拟异常处理，但真实服务项保持未验证。全部关键流程通过并由用户接受后，才进入正式数据采集；只有iOS通过时不默认覆盖鸿蒙。

真实数据替换后重复P02—P09，额外验证去重、更新、来源失效、缺价/营业时间、图片撤权和快照稳定。生产前另做恢复演练、权限/敏感日志审查和商店准备；测试通过不等于商店审核通过。

住宿与快照用例：同一酒店连续两晚仅计两晚费用；住宿不阻塞白天活动；同日两酒店拒绝；最后一晚退房不越界；历史地点失效后仍可重命名/删除/编辑其他地点；替换地点才刷新快照；两类价格单位不可混比较，缺单位的硬价格过滤422。
