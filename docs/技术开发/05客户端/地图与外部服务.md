# 地图与外部服务边界

当前仅设计。已有高德背景；iOS候选高德/Google Maps，服务地区和最终供应商待确认。不将“免费API”理解为地图、搜索、图片、导航、商用存储均永久免费。

## 平台适配接口

MapView接收place_id、经纬度、crs和选中状态；NavigationProvider返回available/unavailable、目的地、url和reason。后端工具交通结果包含source、mode、duration_minutes或null、fetched_at、is_estimate；未知不默认0。地址和时间缺失不交给模型造数。

保存来源原坐标及CRS，展示端要求已知且被供应商支持的坐标。禁止直接将GCJ02改标签为WGS84；转换需要明确实现与测试。客户端导航URL只允许预设scheme/域名与编码参数，第三方数据不能提供任意跳转地址。

## 失败和费用

拒绝定位→手动城市/目的地仍可用；SDK失败→地点列表与地址；外部App未安装→已验证的网页链接（有条件时）或说明不可用；无坐标→禁用导航。地图图片/瓦片离线缓存、POI长期存储均需许可，不随SDK接入自动获准。

客户端Key按Bundle ID/包标识及API范围限制；Web服务密钥仅后端环境注入。开发、测试、生产独立限制/额度；超限关闭对应功能并提示，不能自动开通计费。安全码与Bundle ID根据具体平台Key类型填写，不混用Web端凭据与iOS应用标识。

## 接入时核验入口

- 高德iOS Key：[官方申请指引](https://lbs.amap.com/api/ios-location-sdk/guide/create-project/get-key)。
- Google Maps iOS：[官方用量与计费](https://developers.google.com/maps/documentation/ios-sdk/usage-and-billing)。

链接是后续核验入口，本轮未重新确认现行费率、SDK版本或商业授权。需要用户提供服务商/权限范围和本机私密配置，不在聊天中发送密钥。

AI同样以后端provider接口隔离，只有用户确认免费且许可适用的模型才接真实验证。邮件验证与找回服务待定；真实短信不在本期。模拟结果带provider_mode=mock，生产拒绝模拟。
