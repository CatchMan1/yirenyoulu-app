# 账户、权限与安全设计

尚未实现。用户名/邮箱+密码为首版；短信和微信不接入。用户名3—50位ASCII字母数字下划线，标准化小写且不能含@；邮箱去两侧空白、小写、唯一；口令12—128字符，不去除用户有意空格，不记录正文，使用Argon2id并按部署资源校准参数。

访问令牌15分钟，刷新令牌最长30天、存哈希并轮换。JWT固定算法、issuer/audience/sub(UUID)/session UUID/时间均校验。每次访问检查会话/账户有效性；刷新重放撤销整个会话，改密撤销全部会话，退出撤销当前会话。两端仅一次并发刷新，失败清理会话并返回登录；不得自动重放无幂等保障的写入。

## 所有权矩阵

| 资源 | 匿名 | 本人 | 其他用户 |
|---|---|---|---|
| 有效公共地点/城市/分类 | 读 | 读 | 读 |
| 资料/收藏/行程/任务/会话/消息 | 401 | 按接口读写 | 404 |
| 公共目录写入 | 无 | 无 | 无 |
| 数据导入/迁移 | 无应用接口 | 受限运维身份 | 无 |

子资源同时检查owner和父资源ID；绑定聊天行程必须属于本人；不接收user_id指定归属。无效输入422，版本/幂等冲突409，禁用账户403，限流429，提供方错误503/504。错误details仅字段路径/码，不能回显密码或模型原始内容。

## 注销与恢复

注销验证当前密码，在同一事务撤销会话、取消任务、删除私有行程/地点、会话消息、收藏、偏好与行为；账户保留不能登录的最小墓碑，不保留邮箱/用户名。worker提交再次检查账户状态。备份恢复需重放删除记录，删除审计不携带原个人内容；该机制目前待实施，未经演练不得通过发布验收。

邮箱注册不等于邮箱验证。验证和找回的送信服务未选定；测试用隔离模拟，生产上线前必须确定恢复渠道。重置令牌单次、短时有效且存摘要，成功后撤销所有会话；实现时补独立迁移与契约，不把当前auth_sessions表当成已具备该功能。

## 最小化与日志

仅收集业务必要数据，不记录精确轨迹或无关敏感画像；定位不默认发送到模型，用户主动启用后才发送任务所需最少信息。日志仅事件码/request_id/非敏感耗时与状态，禁止记录口令、令牌、密钥、完整聊天或数据库URL。

登录/注册/刷新按身份及来源限流，统一凭据错误降低账户枚举；TLS、参数化ORM、输入长度/枚举、固定第三方域名、响应大小限制。客户端安全存储保存凭据，普通缓存不存刷新令牌。第三方文本只能作数据，不能覆盖系统工具权限。

上线前确认隐私告知、SDK清单、留存期限、导出/删除流程和适用平台要求。本设计不是法律审核结论，也不沿用旧文档法律/税务判断。
