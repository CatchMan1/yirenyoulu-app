# 数据来源与导入设计

地点库按城市逐步扩展，服务浏览、搜索、收藏、地图坐标、规划候选与推荐。第02期已获准在后端闭环基础上先验证少量许可明确的真实样本，客户端验收继续暂缓。提供可自行配置城市运行的批量采集程序；实际全国覆盖与规模另行验证，付费和商业协议需另行确认。

## 来源与权利

当前接入 Wikidata 的 CC0 结构化数据及满足逐条许可条件的 Overture Places 酒店、餐厅快照。Overture 的字段、许可和获取规则见[开放数据补充指南](酒店餐厅开放数据补充.md)。Wikidata [许可范围](https://www.wikidata.org/wiki/Wikidata:Licensing)不包含维基百科正文、链接图片或第三方网站内容。真实样本不导入图片、外部评论或用户身份。OSM 目前仅提供离线映射器，ODbL 署名和数据库共享安排尚未确定，不采集其真实数据。高德、Google 和商业旅游平台不能凭 API Key 取得长期地点库或算法计算授权。

每个正式来源需登记许可 URL、核验依据、字段白名单、计算授权、版本与复核期限。系统默认拒绝未经审核、已到期或已撤回的来源；政策登记不替代真实授权。展示、存储、计算、图片权利分别核对。范围许可另外限定城市、累计记录数、网络请求次数和期限，不能通过重开批次绕过累计预算。

## 数据与身份

共同必需：稳定内部 UUID、source + external_id、kind、名称、城市、来源 URL、带时区的观察时间及有效状态。城市内部 UUID 与来源区划编号分开，通过 namespace + external_id 维护稳定别名。首批仅使用中国大陆城市、Asia/Shanghai 时区及 CNY，不把 Wikidata QID 冒充国家行政区划代码。

三类地点可缺地址、坐标、价格、营业时间和评分；缺失保留 NULL，字段来源表记录 NOT_PROVIDED，不能补零或猜测。坐标完整包含经纬度和 CRS，来源 WGS84 不可改标签伪装 GCJ-02。Wikidata 城市归属通过明确 P131 链与城市中国归属验证；类型采用明确 P31 白名单，无法证明则隔离。无法解析的时间限定不作为当前归属证据，避免把已结束的历史关系当作现状。

金额为整数分。事实价必须附 entry/night/person 单位和 price_conditions，说明日期、票种、入住或消费条件；未知费用与规划估算分开。当前采样器不提供价格、评分、营业时间或图片事实。地点 active 表示目录可用，不证明商家当前营业或开放时段。

## 导入与更新

批量流程为城市核验 → 按城市/类型分页发现 → 地点及归属事实读取 → 持久化页快照 → 隔离批次 → 校验与审核 → 逐行事务应用 → 报告与业务回归；单独实体流程也可经本地manifest暂存。运营入口为本地CLI，客户端和Agent不拥有写入或审批接口。网络只访问明确官方端点，限定实体数、响应大小、超时、请求预算和有限重试；数据库事务内不访问网络。

批次记录来源、城市、类别、输入摘要、政策版本、审核引用、状态和检查点。状态 staged/approved/completed/failed 与逐行 validated/rejected/duplicate/applied/skipped 分开；完成批次不等于所有行已激活。每行地点、外部 ID、字段来源与 cursor 同事务提交，失败行回滚、此前成功行保留；修复可恢复错误后从原检查点继续。

同源稳定 ID 更新原 UUID；旧观察记录不覆盖较新资料。更新按完整允许快照处理，原事实被移除时改为未知。跨源同城市同类型规范化名称的固定长度摘要用于发现疑似重复，不能自动合并；人工确认后只建立别名，不让次来源覆盖主事实。Overture 另按同类地点距离保守暂缓疑似重复；相近不等于同一实体，不自动做地理距离模糊合并，无法确认的候选继续隔离。

普通目录变动不修改已保存行程快照。来源撤回后读取端隐藏事实、推荐模型失效；存储权撤回或到期后运行清理命令，清除地点事实、暂存载荷及相关快照。政策字段收缩采用整来源事实清理并停用，再按新许可审核导入，不隐式保留旧事实。最小审计关联、本地文件和备份的处置范围见[运营指南](地点数据导入与来源管理.md)，不能把现有清理视为任何协议下的完整销毁。

`CollectionRun`保存不可变配置、政策版本、城市/类型进度、状态、错误及180秒租约；`CollectionPage`保存候选ID、游标、归属校验后的快照、拒绝原因及唯一导入批次关联。分页采用固定官方查询与稳定QID游标，不接受任意URL或SQL。先保存候选，再读取事实并固定观察时间；恢复时复用持久化结果，同页批次键保持稳定，避免重复消耗记录额度或重复保存。来源锁与任务租约校验保护暂存、审核和应用，失去租约的进程不能继续写入。

批量程序默认仅暂存，显式`--apply`才授权按固定规则审核与入库；这是操作人的规则授权，不代表逐条人工事实核验。程序可从指定城市列表逐步扩展，全国入口支持城市候选发现，仍不等于完整行政区划名录；程序不自动启动调度。新任务的累计记录/请求预算不得小于来源已用量；重跑不清零，已有政策到期、撤回或版本变更时停止。初次来源登记只覆盖已核实的Wikidata CC0结构化字段，不能扩展到正文或图片。公共接口可能限流、延迟或缺少归属，必须允许停止、恢复及候选被拒绝；候选上限不承诺入库数量。

来源撤权、到期或字段许可收缩的事实清理同时清空采集页载荷，并终止该来源任务；最小任务、候选标识与审计关联仍按来源保留规则处理。

## 验证与运行

开发、测试、生产分别使用独立数据库和凭据。运行代码不提供虚拟地点造数入口；合成样本仅由关键回归测试在隔离测试库中创建。开发产生的行为由服务端标为 test，不进入真实行为推荐效果评估。

真实样本验证三类浏览、搜索、详情、硬过滤、收藏、行程保存及模拟规划/多轮对话的后端链路。坐标格式通过不等于地图 SDK、导航或实际路线可达通过；真实模型、真实地图和移动端另行验收。重复导入、增量、失效、撤权、事务和并发由独立测试验证，不为测试修改真实地点事实。

批量配置、运行、报告、恢复及DBeaver核对见[批量采集运行指南](批量采集运行指南.md)；逐项来源管理、单独实体操作见[地点数据导入与来源管理](地点数据导入与来源管理.md)。当前数量与字段缺口从目标数据库生成质量报告；验收范围和未验证项见[第02期验收](../07测试与交付/第02期验收.md)。日常复核周期见[地点数据维护手册](地点数据维护手册.md)。
