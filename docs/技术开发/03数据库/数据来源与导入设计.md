# 数据来源与导入设计

只有测试数据闭环验收后，才确定正式来源并开始少量真实样本。

## 采集前审批记录

每个来源记录：覆盖城市/地点数量、使用主体、商业展示权、可存字段、缓存期限、更新与删除要求、图片使用权与署名、费用/限流、服务条款版本与核验时间、授权证据负责人。API能返回数据不等于允许长期存储或商用。未知权利不导入生产、不展示图片；费用与额度以已核验的服务条款为准。

三类共通必需：source、external_id、kind、name、city、status、fetched_at、许可记录。坐标需要CRS及范围校验；无坐标允许作为未完整条目入隔离区，不能验收地图。景点价格带票种/计价单位，酒店带每晚/入住条件，餐厅带人均/币种；均可未知，禁止默认0。营业时间保存来源原文和解析状态；评分保存分值与量表；图片独立授权。不可得字段为null并记录缺失原因。

## 可重复导入流程

受限离线命令→临时隔离记录→字段/坐标/来源许可校验→按(source,external_id)幂等更新→生成导入报告→审核后激活。分页游标/检查点、批次ID、原始记录摘要、成功/失败统计需持久化；超时429/5xx有限退避重试，永久字段错误进入待处理列表。

同源以稳定ID匹配；跨源只产生疑似重复候选，依据城市、名称、距离人工核对，不能仅名称自动覆盖。字段冲突保留来源优先级及时间；导入事务不修改历史trip_item快照。来源撤回/地点关闭设置inactive，历史可读并警告；单次查询缺失不立即判定停业。

增量按来源更新时间和内容摘要；若来源限制储存则采用相应缓存/到期清理，不强行套永久地点库。现有data_sources/place_external_ids基础不代表批次/检查点/权利到期处理已实现，实施需补迁移与测试。

## 验收顺序

9个明确虚拟地点用于现有初始化，不生成真实用户行为；单测可用独立事务里的合成坐标测试范围/转换接口，但不能假装是真实地点。正式样本通过浏览、搜索、收藏、地图、Agent、推荐过滤后才能扩大。失效、未知价格、来源撤权、重复导入及失败重试均需回归；原测试资料不混入生产。
