# 一人有路

面向独自旅行者的行程规划与AI伴游应用，支持鸿蒙和iOS。提供景点、酒店、餐厅浏览与搜索、地点收藏、每日行程编辑、地图导航和多轮AI对话。

## 技术栈与开发状态

鸿蒙使用ArkTS/ArkUI，iOS使用React Native + TypeScript，后端使用Python FastAPI、PostgreSQL和Alembic。两端分别构建与发布，共用业务接口。

第01期已实现44个后端操作、持久规划任务、协同推荐批处理、聊天与账户管理，并提供鸿蒙源码及新版接口接入。鸿蒙编译、运行和前后端联调本期暂缓；iOS工程尚未实现。第02期增加来源政策、受控导入、城市独立推荐，以及按城市自动发现、分页获取和断点入库程序；已在隔离开发库验证北京、上海、杭州共13条 CC0 真实地点；仓库不附带数据库或原始载荷。地图、模型和邮件的真实服务尚未验证，不代表生产或上架验收通过。

