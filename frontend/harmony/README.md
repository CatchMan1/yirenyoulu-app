# 鸿蒙客户端源码

ArkTS/ArkUI；沿用原工程的SearchBar、BottomNavigation、主题与应用资源，按新版UUID、事实空值、持久行程与任务契约重组页面。无短信、足迹、订单或旧版缓存行程入口。这里只包含客户端源码，不含签名、证书、密钥或原运行配置。

## 开发准备

原工程基线为HarmonyOS6.0.1/API21、Hvigor模型6.0.1。使用匹配的DevEco Studio与SDK打开此目录，安装依赖并配置本地签名；构建时核对实际可用的Hvigor/ohpm版本。当前未执行ArkTS编译、模拟器/真机测试及前后端联调，不提供已通过构建的声明。

AppConstants.API_BASE_URL默认指向不可用的example.invalid地址，接入独立后端时明确配置HTTPS/api/v1地址；需要本地HTTP调试时另行核对平台网络策略，正式包不得保留调试地址。应用Bundle标识沿用工程基线，正式签名、商店归属与地图平台绑定仍需受控配置。

## 页面与服务

- LoginPage：用户名/邮箱密码登录、注册、邮件找回；未配置邮件返回明确不可用。
- MainPage：推荐/目录/搜索/分类、收藏、行程列表、资料/偏好、改密、邮箱验证、退出和注销。
- PlaceDetailPage：资料、来源、价格/时间/坐标未知状态、收藏和导航降级。
- TripPlanningPage：手动创建、持久规划任务、同键提交重试、本人任务恢复、轮询/取消与终态。
- TripDetailPage：每日安排、住宿项目、地点增删改、行程编辑及version冲突后刷新。
- AiAssistantPage：本人会话、行程绑定、历史翻页、多轮对话、失败消息原位重试。

ApiClient负责HTTP生命周期、201/202/204、统一错误与刷新单飞；TravelApi和DataGuard处理DTO边界，页面不解析任意JSON。页面加载使用代次防迟到结果覆盖；轮询在页面离开时停止，错误停止后显式重试。

凭据仅在进程内保存，不进入AppStorage、Preferences、日志或路由参数。进程退出后重新登录；平台受保护的持久存储、应用前后台恢复和真实导航启动尚未验证。切换账户递增会话代次，旧响应不得复活或跨用户重放。

地图当前使用后端导航降级，缺坐标显示未知，未接入真实地图画面/外部导航启动。免费模型与邮件也未真实接入。所有页面及平台能力必须在具备工具链后编译、运行和联调验收，再决定正式发布。

类型更新使用仓库根目录scripts/generate_harmony_models.py；类型一致性检查不等同于ArkTS编译或客户端测试。
